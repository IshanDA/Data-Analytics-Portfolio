
# Bank Marketing Analysis

##  Objective

The goal of this project is to analyze customer data from a bank marketing campaign to identify factors that influence customer conversion and improve campaign effectiveness.

---

##  Tools Used

- Microsoft Excel
- Data Cleaning & Transformation
- Pivot Tables & KPI Analysis
- Exploratory Data Analysis (EDA)

---

##  Dataset Description

The dataset contains customer-level information including:
- Age
- Job
- Marital Status
- Balance
- Contact Duration
- Campaign Outcomes

---

##  Approach (CRISP-DM Methodology)

1. **Business Understanding**
   - Understand campaign goals and conversion metrics

2. **Data Understanding**
   - Explore customer attributes and campaign data

3. **Data Preparation**
   - Cleaned missing values and formatted variables

4. **Analysis**
   - Created KPIs and performed segmentation analysis

5. **Evaluation**
   - Identified key factors impacting conversion

---

##  Key Insights

-  Conversion rate is approximately **11–12%**
-  **Call duration** has a strong positive impact on conversion
-  Customers aged **30–50** show higher response rates
-  Higher account balance correlates with better conversion
-  Some job categories show lower engagement

---

## Business Recommendations

- Focus campaigns on high-response age groups
- Optimize call strategies to increase duration quality
- Target high-balance customers for better ROI
- Improve engagement strategies for low-performing segments
