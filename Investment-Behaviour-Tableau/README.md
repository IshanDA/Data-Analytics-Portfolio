
#  Investment Behaviour Analysis (Tableau)

##  Objective

The objective of this project is to analyze investor behavior and preferences based on demographic and financial factors, and to visualize insights using an interactive Tableau dashboard.

---

##  Tools Used

- Tableau
- Data Visualization
- Dashboard Design
- Exploratory Data Analysis (EDA)

---

##  Dataset Description

The dataset includes:
- Age Group
- Income Level
- Investment Type (Stocks, Mutual Funds, etc.)
- Risk Appetite
- Investment Preferences

---

## Dashboard Overview

The Tableau dashboard provides:
- Investor distribution across age groups
- Preferred investment types
- Risk appetite segmentation
- Income vs investment behavior

---

##  Key Insights

- Mutual funds are the most preferred investment option
-  Younger investors tend to take higher risks
-  Higher income groups invest more in diversified assets
-  Risk appetite varies significantly across demographics

---

##  Business Use Cases

- Helps financial advisors understand customer preferences
- Supports targeted investment recommendations
- Improves customer segmentation strategies
