## Projects Included

###  Excel Projects

1. **Bank Marketing Analysis**

   - Identified key drivers like age, balance, and call duration
   - Created KPIs and customer segmentation

2. **Superstore Sales Analysis**
   - Analyzed sales, profit, and discount impact
   - Identified loss-making products and regions
   - Provided recommendations to improve profitability

3. **E-Commerce Analysis**
   - Studied logistics, shipping, and storage costs
   - Identified inefficiencies in operations
   - Analyzed user engagement metrics

4. **Global Pollution Analysis**
   - Analyzed AQI and pollution trends across countries

5. **Hospital Charges Analysis**
   - Analyzed healthcare costs and Medicare coverage
   - Identified gaps between charges and payments
   - Highlighted cost inefficiencies in healthcare systems
