
#  Retail Sales Dashboard (Tableau)

##  Objective

The objective of this project is to visualize retail sales and profit data to identify trends, regional performance, and profitability insights using an interactive Tableau dashboard.

---

##  Tools Used

- Tableau
- Data Visualization
- Dashboard Design
- Business Analysis

---

##  Dataset Description

The dataset includes:
- Sales
- Profit
- Region
- Category & Sub-category
- Discounts

---

##  Dashboard Overview

The Tableau dashboard highlights:
- Sales and profit trends over time
- Regional performance comparison
- Category-wise performance
- Impact of discounts on profit

---

## Key Insights

-  Some regions perform better consistently in sales
-  High discounts negatively impact profitability
-  Certain categories generate high sales but low profit
-  Profitability varies significantly across regions

---

##  Business Use Cases

- Helps businesses track performance visually
- Supports decision-making through dashboards
- Identifies loss-making areas quickly
