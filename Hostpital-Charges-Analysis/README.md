#  Hospital Charges Analysis

##  Objective

The objective of this project is to analyze hospital billing data to understand the gap between charged amounts and actual payments, and to identify inefficiencies in the healthcare cost structure.

---

##  Tools Used

- Microsoft Excel
- Data Cleaning & Transformation
- Exploratory Data Analysis (EDA)
- KPI Analysis

## Dataset Description

The dataset includes:
- Hospital Charges
- Medicare Payments
- Number of Procedures
- Provider Information

---

##  Approach (CRISP-DM Methodology)

1. **Business Understanding**
   - Analyze cost structure in healthcare system

2. **Data Understanding**
   - Explore differences between charges and payments

3. **Data Preparation**
   - Cleaned and structured dataset

4. **Analysis**
   - Compared charges vs actual payments
   - Identified trends across hospitals

5. **Evaluation**
   - Measured inefficiencies and cost gaps

---

## Key Insights

-  Hospitals charge significantly higher than actual payments
-  Medicare covers a large portion of cases (~80–85%)
-  Huge gap exists between billed and paid amounts
-  Certain procedures show extreme cost variation

---

##  Business Recommendations

- Improve pricing transparency in healthcare
- Optimize hospital billing strategies
- Reduce unnecessary cost inflation
- Focus on cost standardization across providers
